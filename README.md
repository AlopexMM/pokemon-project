# Instrucciones para la instalación del entorno de Pokedex

Solo se necesita tener instalado docker segun tu sistema operativo

- [Linux](https://docs.docker.com/desktop/setup/install/linux/)
- [MAC](https://docs.docker.com/desktop/setup/install/mac-install/)
- [Windows](https://docs.docker.com/desktop/setup/install/windows-install/)

## Correr el proyecto

En la consola nos paramos dentro de la carpeta docker y ejecutamos el siguiente comando

```bash
docker-compose up
```

> El uso de docker compose puede variar entre sistemas operativos

# Instructions to install Pokedex environment

You need to have installed docker for your operating system

- [Linux](https://docs.docker.com/desktop/setup/install/linux/)
- [MAC](https://docs.docker.com/desktop/setup/install/mac-install/)
- [Windows](https://docs.docker.com/desktop/setup/install/windows-install/)

## Run the project

In the terminal go to the docker folder and then run the command

```bash
docker-compose up
```

> This may vary depending on the different operating systems.
